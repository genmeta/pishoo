# Execution interface

`runtime.wit` defines the Pishoo generic command execution contract.

The `deps/` files are the standard WASI 0.2.12 filesystem, clocks and I/O interfaces, copied from `wasip2 1.0.4+wasi-0.2.12`. Their upstream project is https://github.com/WebAssembly/WASI and their original comments and declarations are preserved.
